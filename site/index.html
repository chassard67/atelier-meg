Atelier MEG

Installer l'extension sur Google Chrome ou Microsoft Edge — environ 5 minutes

⬇ Télécharger l'extension (v{{EXT_VERSION}})
Atelier MEG ajoute des outils à Mon Expert en Gestion (téléchargement en lot des factures d'achat, impression groupée, code de sécurité automatique…). Elle s'installe en « mode développeur » et se met ensuite à jour toute seule.
Prérequis 1. Télécharger 2. Décompresser 3. Chrome 3 bis. Edge 4. Sélectionner le dossier 5. Scripts utilisateur 6. Épingler 7. Mise à jour auto Vérification
Avant de commencer. Il faut Google Chrome ou Microsoft Edge à jour (version 120 minimum). Les étapes 1, 2 et 4 à 7 sont communes ; l'étape 3 diffère selon le navigateur (étape 3 pour Chrome, étape 3 bis pour Edge — faites celle qui vous concerne).

1 Télécharger l'extension

Cliquez sur le bouton ci-dessous (ou en haut de page) pour récupérer le fichier atelier-meg-extension.zip.

⬇ Télécharger l'extension (v{{EXT_VERSION}})

Le fichier arrive dans votre dossier Téléchargements.

2 Décompresser dans vos Documents

Dans l'explorateur de fichiers, créez le dossier Documents\AtelierMEG\extension, puis extrayez-y tout le contenu du zip (clic droit sur le zip → Extraire tout…).

Gardez toujours ce même dossier : les mises à jour s'y feront automatiquement.

Après extraction, le dossier extension contient directement manifest.json et les autres fichiers.

3 Sur Google Chrome — ouvrir les extensions

Dans la barre d'adresse, tapez chrome://extensions puis Entrée. En haut à droite, activez Mode développeur, puis cliquez sur Charger l'extension non empaquetée.

Vous utilisez Edge ? Passez directement à l'étape 3 bis ci-dessous.

3b Sur Microsoft Edge — ouvrir les extensions

Dans la barre d'adresse, tapez edge://extensions puis Entrée. En bas à gauche, activez Mode développeur, puis cliquez sur Charger l'extension décompressée.

Vous utilisez Chrome ? C'était l'étape 3 ci-dessus.

4 Sélectionner le dossier de l'extension

Dans la fenêtre qui s'ouvre, sélectionnez le dossier Documents\AtelierMEG\extension puis validez.

La carte « Atelier MEG » apparaît alors dans la liste des extensions.

5 Autoriser les scripts utilisateur (indispensable)

Sur la carte « Atelier MEG », cliquez sur Détails, puis activez Autoriser les scripts utilisateur.

Sans cette étape, aucun outil ne s'exécute. Si vous ne voyez pas l'option, votre navigateur est un peu ancien : il suffit que le « Mode développeur » (étape 3) reste activé.

6 Épingler l'extension

Cliquez sur l'icône pièce de puzzle 🧩 (en haut à droite du navigateur), puis sur l'épingle à côté d'« Atelier MEG » pour garder son icône visible.

7 Activer la mise à jour automatique (recommandé, une seule fois)

Pour que l'extension se mette à jour toute seule à l'avenir : ouvrez le dossier Documents\AtelierMEG\extension\maj et double-cliquez une seule fois sur activer-maj-auto.cmd. C'est tout.

Sans cette étape, les fonctionnalités se mettent quand même à jour seules ; seule l'extension elle-même (rare) devra être réinstallée à la main — un bandeau vous préviendra alors dans MEG.

✓ Vérifier que tout fonctionne

Ouvrez (ou rechargez) Mon Expert en Gestion, page Achats : le badge orange « Affichage personnalisé LGA » doit apparaître. L'icône de l'extension ne porte aucune pastille.

Pastille sur l'icôneSignification
(aucune)Tout fonctionne.
!« Autoriser les scripts utilisateur » n'est pas activé (étape 5).
OFFServeur de publication injoignable (connexion / VPN) ou dépôt supprimé.
MAJ / EXTNouvelle version de l'extension disponible : retéléchargez le zip et extrayez-le par-dessus le dossier (ou laissez faire la mise à jour automatique).
Par dossier, une fois : pour le téléchargement des factures, créez dans chaque société le mode de règlement Téléchargé (Paramètres → Listes par défaut → Modes de règlement : code TELECHARGE, libellé Téléchargé, délai 0, type Virement, compte 99999999). L'extension peut aussi le créer pour vous à la première utilisation.

? Mises à jour et aide

  • Fonctionnalités : automatiques (au démarrage du navigateur, puis régulièrement). Pour forcer : icône Atelier MEG → Vérifier les mises à jour → Recharger les onglets MEG.
  • Extension : automatique si l'étape 7 est faite ; sinon, quand MEG affiche « Nouvelle version », retéléchargez le zip et extrayez-le par-dessus Documents\AtelierMEG\extension (elle se recharge seule).
